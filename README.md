# Número Adivinha

Projeto escolar desenvolvido em Python que simula um jogo de adivinhação de números.

## Sobre o projeto

O programa escolhe aleatoriamente um número entre 1 e 15. O jogador deve tentar descobrir o número secreto, recebendo dicas informando se o palpite é maior ou menor que o número correto.

Ao acertar, o jogador pode registrar seu nome. O programa mantém um placar com os três melhores resultados, considerando a menor quantidade de tentativas.

## Funcionalidades

- Iniciar uma partida;
- Gerar números aleatórios;
- Informar dicas durante as tentativas;
- Registrar o nome do jogador;
- Exibir o placar dos três melhores jogadores;
- Encerrar o programa pelo menu.

## Como executar

Tenha o Python instalado e execute no terminal:

```bash
python numero_adivinha.py
```

## Tecnologias utilizadas

- Python
- Biblioteca `random`
- Estruturas condicionais e de repetição
- Entrada e saída de dados pelo terminal

## Objetivo

Este projeto foi desenvolvido como atividade escolar para praticar conceitos básicos de programação em Python, como variáveis, condicionais, laços de repetição, funções da biblioteca padrão e interação com o usuário.
